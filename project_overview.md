# FamilyRoots Platform - Project Overview

> **Source Project:** Google Stitch (`https://stitch.withgoogle.com/projects/11773336292413241008`)  
> **Design System:** Kinship Modern  
> **Status:** Core User & Admin Modules Complete  

---

## 📌 Executive Summary

**FamilyRoots Platform** is a privacy-first, multi-generational family tree and archive application. It provides a secure, invite-only sanctuary for families to document their lineage, preserve stories, share memories, and coordinate family events while maintaining strict data sovereignty and end-to-end encryption.

---

## 🎨 Design System & Aesthetics

* **Design System Name:** Kinship Modern
* **Color Palette & Theme:** Sleek dark/light hybrid interface with deep navy accents (`#191A1F`), neutral surface containers, and Google Sans typography.
* **Layout Structure:** Standardized split-panel navigation for Admin Control Center and seamless card grid views for the user-facing web app.

---

## 🛡️ Core Security & Privacy Principles

1. **End-to-End Encryption:** Sensitive documents, family archives, and private conversations are client-side encrypted.
2. **Data Sovereignty:** Users retain 100% ownership of their data with full export capabilities in standard formats at any time.
3. **Private Sanctuary:** Invite-only access model ensuring only verified family members can access network hubs.

## 💻 System Modules & Screen Inventory

### 1. User-Facing Application Suite

| Screen Name | Description & Capabilities |
| :--- | :--- |
| **Family Tree (`Famil...`)** | Interactive visual family tree renderer supporting multi-generational views. |
| **Members Directory (`Mem...`)** | Directory of family profiles with relationship labels (e.g., Niece, Cousin, Parent). |
| **Relationship Map (`Relati...`)** | Visual connection map displaying inter-family links and lineage ties. |
| **Memories & Stories (`Memo...`)** | Shared family media vault for photos, videos, and audio history recordings. |
| **Events Calendar (`Event...`)** | Coordination hub for reunions, anniversaries, and memorial dates with RSVP tracking. |
| **Invitations & Access (`Invitat...`)** | Secure access management, magic link invites, and family branch permissions. |
| **Documents Archive (`Docu...`)** | High-resolution storage for historical family documents, wills, and certificates. |
| **User Settings (`Settin...`)** | Profile customization, privacy preferences, notification rules, and export controls. |
